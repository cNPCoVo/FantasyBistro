# FantasyBistro · 奇幻餐厅

当前基线：`0.2.0-quantity-cart`。开发试玩版，完整首章尚未完成。这里是游戏下载仓库。

## Windows 电脑版

[点击下载电脑游戏 ZIP](https://github.com/cNPCoVo/FantasyBistro/releases/download/v0.2.0-quantity-cart-preview.1/FantasyBistro-0.2.0-Windows-x64.zip)

完整解压后双击 `FantasyBistro.exe`，保留同目录的 `FantasyBistro.pck`，无需另装 Godot。支持 Windows 64 位 / OpenGL 3.3。包内附运行说明与许可。

已通过 960×540、1280×720 窗口导航、真实采购、防重复扣款与独立进程存档恢复。其他硬件、DPI 和长期体验未全面验证。

## 下载与存档

[完整发布页](https://github.com/cNPCoVo/FantasyBistro/releases/tag/v0.2.0-quantity-cart-preview.1)。下载 Assets 中的游戏附件，GitHub 自动生成的 Source code ZIP 只有仓库说明，不是游戏。

包内没有玩家存档、账户文件、参考 APK 或他人游戏素材。Windows 本机原存档位置保持 `%APPDATA%\FantasyBistro\saves`；下载不会自动同步电脑与手机进度。

游戏原创代码与内容没有在此授予开源许可。Godot 引擎及其第三方许可随 Windows 构建附带。
