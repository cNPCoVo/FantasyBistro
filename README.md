## Windows 电脑版

[下载电脑游戏 ZIP（约37MB）](https://github.com/cNPCoVo/FantasyBistro/releases/download/v0.2.0-quantity-cart-preview.1/FantasyBistro-0.2.0-Windows-x64.zip)

## 操作与存档

[完整发布页](https://github.com/cNPCoVo/FantasyBistro/releases/tag/v0.2.0-quantity-cart-preview.1)提供操作说明与SHA256校验值。请下载Assets中的游戏包；GitHub自动生成的Source code ZIP只有仓库说明，不是游戏。

右下菜单 → 系统设定 → 保存 / 读取进度。营业读档后先暂停，点击恢复进度继续。安卓返回键使用原Esc逻辑取消/返回/打开菜单。

包内没有玩家进度、账户、签名密钥、参考APK或他人游戏素材。Windows本机原存档位置保持 `%APPDATA%\FantasyBistro\saves`；安卓在应用内部保存，卸载可能删除本地进度。电脑与手机不自动同步存档。

游戏原创代码与内容未授予开源许可。Godot及第三方版权通知随Windows包和APK的assets/licenses附带。其他硬件、DPI、后台切换及长期真人体验未全面验证。
