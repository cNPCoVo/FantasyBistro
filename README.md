# FantasyBistro · 奇幻餐厅

这是游戏下载仓库，当前开发基线为 `0.2.0-quantity-cart`。游戏仍为开发试玩版，完整首章尚未完成。

## 下载

游戏包正在制作与验证。完成后请在 [Releases](https://github.com/cNPCoVo/FantasyBistro/releases) 下载对应系统附件；不要把 GitHub 的 Source code ZIP 当作游戏。

- Windows：准备可直接运行的 64 位游戏包。
- Android：正在核对导出工具与触控，尚未发布可验证的 APK。

不上传玩家存档、账户文件、参考 APK 或他人游戏素材。下载不会自动同步电脑与手机存档。

游戏原创代码与内容没有在此授予开源许可。Godot 引擎及其第三方许可随构建附带。
